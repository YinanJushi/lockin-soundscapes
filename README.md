# Lock-in Soundscapes

Thirty 30-minute instrumental tracks for studying, sorted by how much push you need.

- **Genres** — three instrument families (Electronic, Orchestral, Groove) at three energy levels (Low, Mid, High).
- **Scenes** — seven places (late-night city, snowfall, rainy café, summer fields, night train, library, mountain temple), each in a Read (low) and Study (mid) version.
- **Acoustic set** — seven warm plucked and struck pieces.

Design rules, from research on focus music: no lyrics or voice-like sounds, steady loudness with no sudden jumps, repetition with slow variation, no sharp transients, and energy matched to the task.

All music is synthesized in code (Python, numpy/scipy) — no samples or recordings. Audio is MP3, 96 kbps.

Open `index.html` through any static web server, or visit the GitHub Pages site.
